## ✦ 1.1.8

- Dragon's Breath now gives **Cosmic Strength** (cosmic damage +30 %, stronger and longer cosmic effects).
- New optional file **Stellar Surfer Visuals**: the client part of this mod (constellation skill tree, Origins window skin, glowing orbs) for players who use the datapack + resource pack. Install EITHER this mod OR the Visuals add-on with the packs, never both.

Requires **Origins** and **Apoli** (NeoForge), Minecraft 1.21.1, on client and server. Do not install the datapack or resource pack zips alongside this jar. Found a bug? https://github.com/InLighTs28/stellar-surfer/issues
